# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer built using **Python, Flask, NLP, and Machine Learning** that analyzes resumes, extracts skills, calculates ATS scores, and compares resumes with job descriptions.

---

# 📌 Features

✅ Upload Resume PDF
✅ Extract Resume Text
✅ Skill Extraction using NLP
✅ ATS Score Calculation
✅ Job Description Matching
✅ Clean Flask Web Interface
✅ Resume vs JD Similarity Analysis

---

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Iswarya-0876/resume-analyzer.git
```

---

## 2️⃣ Open Project Folder

```bash
cd resume-analyzer
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate:

```bash
venv\Scripts\activate
```

---

## 4️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Project

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```

---

# 📊 How It Works

1. User uploads resume PDF
2. PDF text is extracted
3. Skills are identified
4. ATS score is calculated
5. Resume is compared with Job Description
6. Match percentage is displayed
